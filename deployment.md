# Deployment options

Choose where WildEdge ingests, stores, and queries your telemetry. Your models can run on devices, call a hosted API, or run on your own infrastructure.

| Option | Where WildEdge runs |
| --- | --- |
| **SaaS** | In the WildEdge hosted service. [Sign in](https://app.wildedge.dev/) to create a project and connect a telemetry source. |
| **Bring your own cloud (BYOC)** | In your own cloud environment, within your network perimeter. |
| **On-premises** | On infrastructure you operate, including environments with restricted connectivity. |

[Contact WildEdge](mailto:contact@wildedge.dev) to discuss BYOC or on-premises requirements. See [Architecture](/architecture) for the data path and [Models](/monitoring/models) to monitor models already sending telemetry.
